# Задание 3.22. Примеры кода (Flexbox)

## Что сделано

Изучены примеры в папке `sample` по CSS Flexbox.

### Итоги

- **display: flex** — контейнер становится флексом, дочерние элементы — флекс-элементами.
- **flex-direction** — направление главной оси (row, row-reverse, column, column-reverse).
- **justify-content** — выравнивание по главной оси (flex-start, flex-end, center, space-between, space-around, space-evenly).
- **align-items** — выравнивание по поперечной оси (stretch, flex-start, flex-end, center, baseline).
- **align-self** — выравнивание отдельного элемента по поперечной оси.
- **flex-wrap** — перенос элементов на следующую строку (nowrap, wrap, wrap-reverse).
- **flex-grow**, **flex-shrink**, **flex-basis** и краткая запись **flex** — рост, сжатие и базовый размер флекс-элементов.

Изменение значений в примерах показывает, как меняется расположение блоков; в DevTools во вкладке «Стили» видны вычисленные значения flex-свойств.
