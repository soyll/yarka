# Задание 3.12. Верстка по стилям

## Что сделано

В папке `sample` заполнен **index.html** элементами в соответствии с селекторами из **css/style.css**.

- **header** — блок шапки с `img.logo` и `h1`.
- **.container** — основной контейнер страницы.
- **.dishes** — обёртка для карточек блюд (flex, wrap, justify-content).
- **.dish** — карточка блюда: блок **.info** (название `p.dish-info-name`, цена `p.dish-info-price`, описание, `span.select`) и блок **.photo** с `img`.
- **footer** с абзацем.

Добавлены три блюда (пицца, бургер, салат Цезарь) с использованием изображений из папки `images`. Контент произвольный, структура соответствует описанным в CSS классам и селекторам.
