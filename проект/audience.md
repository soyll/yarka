## Детализация по сегментам

### 1. Урбанист (25–40)

| Критерий | Описание |
|----------|----------|
| **Портрет** | Специалист IT/офис, живёт в новостройке или центре, подписан на городские Telegram-каналы |
| **Сценарий** | Увидел push «Голосование за освещение в парке Энгельса» → открыл с телефона → выбрал Октябрьский → проголосовал в метро |
| **UX-приоритеты** | Минимум шагов, district-selector в один тап, карточки с бюджетом и статусом |
| **Риск оттока** | Долгая регистрация, нет фильтра «только мой район» |
| **Референс поведения** | Рекорд ФКГС 2025 — 389 тыс. голосов; пик активности с мобильных (МК Екатеринбург) |

### 2. Хозяйка района (45–60)

| Критерий | Описание |
|----------|----------|
| **Портрет** | Пенсионерка или работающая в смену, активна в чате дома, ходит на собрания ТСЖ |
| **Сценарий** | Зашла с ноутбука в библиотеке → выбрала Орджоникидзевский → нашла «Лавки у ДК Орджоникидзе — исполнено» → показала соседям |
| **UX-приоритеты** | Крупный текст, контраст, блок «Отчёт о тратах», статусы цветом (зелёный/оранжевый/красный) |
| **Риск оттока** | Мелкий шрифт, жаргон («инициативная группа», «протокол») без пояснений |
| **Референс поведения** | Программа «Екатеринбург, предлагай!» — инициаторы собирают протоколы на местах (URBC) |

### 3. Родитель с коляской (28–38)

| Критерий | Описание |
|----------|----------|
| **Портрет** | Молодая семья, decathlon-коляска, жалуется в чате ЖК на ямы и темноту у подъезда |
| **Сценарий** | Push от УК → одним большим пальцем «Проголосовать» → видит прогресс бюджета района |
| **UX-приоритеты** | Touch targets ≥ 44 px, hero с понятным слоганом, pill-кнопки |
| **Риск оттока** | Горизонтальный скролл районов, модалки без закрытия |
| **Референс поведения** | Волонтёры ФКГС помогают голосовать «на месте» — нужен такой же простой digital-аналог |

## Вывод для вёрстки

1. **Mobile-first** — приоритет родителю и урбанисту (≈70% трафика по аналогии с ФКГС).
2. **District-selector** — обязателен для всех трёх сегментов; активный район сохранять визуально.
3. **Статусы инициатив** — три состояния из ТЗ: «Голосование», «Исполнено», «Ждёт бюджета» — закрывают потребность хозяйки района в прозрачности.
4. **Hero** — слоган «10 минут в месяц» снимает барьер «нет времени» у всех сегментов.
