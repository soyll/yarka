# Проект «Зеленая Ставка» — Екатеринбург

Платформа участия жителей в распределении бюджета района. Три этапа: бриф, анализ ЦА, многостраничный сайт.

---

| Файл | Содержание |

| `brief.md` | Псевдобриф заказчика с референсами ФКГС и «Екатеринбург, предлагай!» |

| `ts.md` | Техническое задание: палитра, компоненты, районы |

---

## UI-концепция: «Карта ставок»

Центральная идея — не generic landing, а **интерактивная карта 11 районов** как главный интерфейс:

- Наведение/клик по району → панель с бюджетом и голосами
- Переход на паспорт района (ВИЗ, Уралмаш)
- Метафора «зелёной ставки» — голос жителя за проект своего района

Дополнительные фишки:

- **3D-карта MapLibre GL** — 11 разноцветных extruded-районов, pitch 55–62°, тёмный basemap CARTO
- **Точки идей** — 8 маркеров с mock prerender-превью (SVG), pulse-анимация, popups с фото
- **Ставка дня** — featured-инициатива с кольцевым countdown до дедлайна
- **Копилка района** — визуализация освоения бюджета (jar + progress)
- **Лента активности** — бегущая строка «кто проголосовал»
- **До/после** — слайдер на странице исполненной инициативы
- **Unbounded** для заголовков + тёмные editorial-секции
