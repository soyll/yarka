# Задание 5.3. Гибридная вёрстка

В [sample/style.css](sample/style.css) применена гибридная схема: `display: table` для `.container`, `table-caption` для `header`, `table-cell` для `section` и `aside`; убраны float и фиксированные width у колонок. В aside добавлено изображение.
