# Задание 3.43. Выпадающий список

## Что сделано

В папке `sample` изучены верстка страницы и файл **style/menu.css**, в котором реализовано выпадающее меню.

- Принцип работы: пункты меню с вложенными списками (ul внутри li); по умолчанию вложенное меню скрыто (display: none или visibility/height). При наведении на родительский пункт (li:hover или nav li:hover) вложенный блок показывается (display: block или аналогично). Позиционирование (position: absolute у вложенного ul, relative у li) обеспечивает наложение выпадающего блока над контентом. Комментарии в коде по правилам не оставлялись. При желании можно предложить свой вариант (например, на чистом CSS с :hover и дочерними селекторами).
