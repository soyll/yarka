# Задание 3.55. Сложные формы

## Что сделано

Изучены файлы **index.html** (стилизованные элементы форм) и **toggle.html** (чекбокс, оформленный как переключатель on/off).

- В **index.html** элементы форм уже частично стилизованы; при необходимости правки вносятся в **style.css** (границы, отступы, цвета, :focus/:hover).
- В **toggle.html** разобран пример: скрытый input type="checkbox", label как видимая кнопка переключателя; состояние «включено» задаётся через **:checked** и соседний селектор (или общий контейнер с последующим выбором по :checked). Визуально переключатель меняет фон/положение в зависимости от состояния чекбокса. Комментарии в коде не добавлялись.
