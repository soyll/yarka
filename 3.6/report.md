# Задание 3.6. Анализ кода

## Что сделано

Изучены файлы в папке `sample`: `sample.html` и `sample.css` (включая комментарии в коде).

### Итоги

- **Универсальный селектор `*`** — отступы заданы всем элементам.
- **Селектор по типу `p`** — ко всем абзацам: выравнивание вправо, отступ первой строки, шрифт, размер.
- **Селектор по классу `.select`** — заливка и рамка у элементов с `class="select"` (в примере: абзац и таблица выглядят одинаково по фону и границе).
- **Селектор по id `#first`** — цвет текста и подчёркивание у элемента с `id="first"`.
- **Селектор по атрибуту `input[type=button]`** — отдельное оформление кнопки по сравнению с текстовым полем.

Разные способы обращения к элементам (тип, класс, id, атрибут) дают разное оформление при одной и той же разметке; один и тот же класс у разных типов элементов (p, table) применяет к ним одни и те же стили.
