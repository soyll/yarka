# Задание 3.8. Специфичность стилей

## Что сделано

Изучены теоретический материал и примеры (sample-1, sample-2) по специфичности.

### Итоги

- **Специфичность** — способ браузера выбрать, какое значение свойства применить при конфликте. Вес правила задаётся типами селекторов.
- **Порядок по возрастанию специфичности:** селекторы типа (element, псевдоэлементы) → классы, атрибуты, псевдоклассы → идентификаторы. Наследованные правила слабее правил для самого элемента.
- При **равной специфичности** побеждает правило, объявленное последним.
- **Встроенные стили** (атрибут `style`) имеют наивысший приоритет.
- Универсальный селектор `*`, комбинаторы (+, >, ~) и `:not()` в расчёте специфичности не учитываются (селекторы внутри `:not()` учитываются).
- **!important** даёт объявлению наивысший приоритет; при нескольких !important сравнивается специфичность. Использовать только в исключительных случаях.
