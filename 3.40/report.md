# Задание 3.40. Настройка текста

## Что сделано

В папке `sample` оформлен фрагмент из **sample.txt** (М. Булгаков «Мастер и Маргарита»).

- Создан **index.html**: разметка с заголовком книги, автором, изданием, примечанием; часть и глава вынесены в заголовки (h2, h3); эпиграф — в **blockquote** с **cite**; основной текст — в абзацах **p**.
- Создан **style.css**: шрифт Georgia (serif), размер и межстрочный интервал, цвет текста и фона; выравнивание заголовков по центру; отдельные стили для .book-header, .author, .title, .part, .epigraph, .chapter; абзацы с **text-align: justify**, **text-indent: 2em**; эпиграф с левой границей и фоном. Цветовая гамма — нейтральная (серый текст, бежевый фон, акцент рамки эпиграфа). Ударения в HTML при необходимости задаются через тег **&lt;span class="stress"&gt;** и CSS или через символ U+0301.
