# Задание 4.3. Рисование простых фигур

## Что сделано

В [sample/index.html](sample/index.html) заданы классы для 14 фигур. В [sample/style.css](sample/style.css) реализованы фигуры с разными цветами; пятиконечная звезда — из 3 треугольников (блок + `::before` + `::after` с поворотами), шестиконечная — из 2 пересекающихся треугольников (`::before` вверх, `::after` повёрнут на 180°).

## Изменённые файлы

- `4.3/sample/index.html`
- `4.3/sample/style.css`

## Визуальная проверка

Требуется наблюдение пользователя за отображением фигур и корректировка размеров, цветов и пропорций при необходимости.
