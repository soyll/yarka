# Задание 3.38. Семейства шрифтов

## Что сделано

Ознакомление с материалом по семействам шрифтов (без практического задания).

### Итоги

- **Веб-безопасные шрифты** — доступны в большинстве ОС (Arial, Courier New, Georgia, Times New Roman, Trebuchet MS, Verdana и др.), тип (sans-serif, serif, monospace).
- **Пять общих семейств в CSS:** serif, sans-serif, monospace, cursive, fantasy.
- **Стек шрифтов** — в font-family перечисляют несколько имён через запятую; браузер использует первый доступный. В конце указывают generic family (например sans-serif). Названия из нескольких слов — в кавычках ("Trebuchet MS").
