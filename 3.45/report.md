# Задание 3.45. Стилизация таблиц

## Что сделано

Изучены примеры в папке `sample`: стилизация таблиц с использованием **:nth-child()** (odd/even, 2n+1, 2n, формула An+B), а также пример в папке **checked** — скрытие контента по состоянию чекбокса (**:checked**).

### Итоги

- **tr:nth-child(odd)** / **tr:nth-child(2n+1)** — нечётные строки; **tr:nth-child(even)** / **tr:nth-child(2n)** — чётные. Формула **:nth-child(An+B)** задаёт номера элементов. Чередование фона строк улучшает читаемость таблицы.
- В примере **checked**: скрытые элементы с классом .hidden имеют display: none; чекбокс скрыт; label связан с ним по for/id. При :checked у чекбокса соседние или следующие элементы (комбинатор + или ~) получают display: block (или иное), контент показывается. Реализован свой вариант такой «раскрывашки» по тому же принципу (скрытый input, label, CSS по :checked).
