# Задание 3.34. Использование HSL

## Что сделано

Изучен файл примера в папке `sample` (index.html, style.css): базовый цвет в формате **hsl(209, 87%, 24%)** (оттенок, насыщенность, светлота), варианты по насыщенности и светлоте, вторичные цвета по углу цветового круга, «кастомный» светлый оттенок, варианты кнопок (primary, secondary, border, shadow).

Добавлена секция **«Своя палитра»**: монохромная тройка по одному оттенку (hue 140) с разной светлотой (base 30%, light 70%, dark 15%) и акцентный цвет (hue 30, насыщенность 80%, светлота 50%) в файле style.css классы .my-palette-1, .my-palette-2, .my-palette-3, .my-palette-accent. Такой набор подходит для фона, текста и акцентных кнопок.
