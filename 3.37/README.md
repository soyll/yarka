# Задание 3.37. Примеры кода (шрифты)

## Что сделано

Изучены примеры в папке задания: подключение шрифтов (@font-face, Google Fonts), параметры (font-family, font-size, font-weight, font-style, font-stretch, text-decoration и др.).

### Итоги

- Подключение: локальные файлы через @font-face (src: url(...), font-family, font-weight и т.д.), внешние — через link или @import.
- Свойства шрифта и текста задают семейство, размер, начертание, декорации. Изменение значений в примерах показывает влияние на отображение; рекомендуется изучать параллельно с лекцией.
