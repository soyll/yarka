# Задание 3.26. Варианты позиционирования

## Что сделано

Изучены примеры в папке `sample` (relative.html, absolute.html, fixed.html, stiky.html, z-index.html) и комментарии в коде.

### Итоги

- **position: relative** — элемент остаётся в потоке, смещение через top/right/bottom/left относительно своей исходной позиции; исходное место остаётся занятым.
- **position: absolute** — элемент выносится из потока, позиционируется относительно ближайшего предка с position не static (или относительно окна); блок не резервирует место в документе.
- **position: fixed** — относительно окна просмотра (viewport), при прокрутке остаётся на месте.
- **position: sticky** — гибрид relative и fixed: до достижения порога ведёт себя как relative, после — как fixed в пределах родителя.
- **z-index** — порядок наложения по оси z; действует только у позиционированных элементов (не static). Большее значение — выше по стеку.

Изменение значений в примерах показывает сдвиг блоков и наложение; в DevTools видно вычисленные координаты и z-index.
