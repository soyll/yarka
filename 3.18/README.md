# Задание 3.18. Настройка документа

## Что сделано

В папке `sample` в **index.html**:

- Добавлены недостающие элементы и сгруппированы блоки: иллюстрации (три изображения), текст (два абзаца), список, таблица — каждая группа обёрнута в `div.group`.
- Для каждого раздела добавлены заголовки **h4** (Иллюстрации, История праздника, Праздники 8 марта, Список лучших подарков).
- В блоке `<style>` заданы стили: группы выровнены по центру (`margin: 0 auto`), ширина групп **80%**; у группы с изображениями картинки в одну строку через `display: inline-block`, `max-width: 30%`; у групп заданы отступы и выравнивание текста (поля и отступы через `padding`, `margin-bottom`).

Файл **style.css** использован без изменений (таблица, заголовки). Изображения помещаются в одну строку за счёт inline-block и ограничения ширины.
