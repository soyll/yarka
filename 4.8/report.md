# Задание 4.8. Слайдеры

## Что сделано

В [sample/gallery.html](sample/gallery.html) три раздела галереи заменены слайдерами: автоматическая смена по времени (opacity + `@keyframes round`), по клику на радиокнопки (`translateX` ленты), осенний блок — смена по стрелкам (`container_arrow`, Font Awesome, радиокнопки и `:checked`). В [sample/style/style.css](sample/style/style.css) добавлены стили слайдеров; скопированы изображения в `sample/media/`.

## Изменённые файлы

- `4.8/sample/gallery.html`
- `4.8/sample/style/style.css`
- `4.8/sample/media/` (из `.data`)

## Визуальная проверка

Требуется наблюдение пользователя за работой слайдеров, таймингом и выравниванием кадров; при необходимости подстроить размеры `.container_slider` и задержки.
