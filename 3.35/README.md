# Задание 3.35. Верстка по макету (LiveTV)

## Что сделано

В папке `sample` проверены и при необходимости дополнены стили в **style/style.css** для соответствия эталону.

- Подключён шрифт Golos (@font-face), базовые стили (wrapper 90%, иконки, типографика). Навигация: flex, два блока меню (left/right), список .menu без маркеров, flex для пунктов. Баннер, карточки контента, кнопки и прочие блоки стилизованы по классам из разметки (banner, banner-text, rounded, text-title и т.д.). Ориентация на названия классов в HTML обеспечивает соответствие эталону; при необходимости правки вносятся в style.css к соответствующим селекторам.
