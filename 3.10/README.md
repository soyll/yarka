# Задание 3.10. Комбинаторы CSS

## Что сделано

Изучены файлы в папке `sample` (sample-1–5, style.css) и форма записи комбинаторов.

### Итоги

- **Запятая (A, B)** — выбор всех элементов, совпадающих с A или B, независимо от положения в DOM.
- **Пробел (A B)** — потомки: все A внутри B на любом уровне вложенности.
- **Строгий дочерний (A > B)** — только прямые дети: B, у которых родитель A.
- **Смежный (A + B)** — один следующий сосед: элемент B, сразу идущий после A.
- **Соседний (A ~ B)** — все следующие соседи: элементы B, идущие после A в общем родителе.

По разметке и селекторам в примерах видно, к каким элементам обращается каждое правило; смена классов и структуры меняет набор выбранных элементов.
