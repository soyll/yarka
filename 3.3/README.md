# Задание 3.3. Подключение стилей

## Что сделано

- В папке `sample` создан файл **index.html** с разметкой: `body` → `section` → заголовки `h1`, `h2`, абзац `p`, список `ul` с пунктами `li` (в соответствии с типовой структурой для подключения внешних стилей).
- По умолчанию подключён `style_1.css`. Для проверки с другими файлами в `<head>` можно заменить ссылку на `style_2.css` или `style_3.css`, либо подключить несколько файлов подряд.

## Выводы (без просмотра содержимого файлов стилей)

- **Один файл:** внешний вид страницы определяется выбранным файлом (каждый задаёт свои цвета фона, шрифты, отступы, оформление списка).
- **Несколько файлов, порядок подключения:** при совпадении селекторов и свойств побеждает правило из файла, подключённого последним (каскад).
- **Дублирование:** в разных файлах часто задаются одни и те же свойства для одних и тех же элементов (body, section, h1, h2, p, ul, li) — фон, размер шрифта, отступы, оформление списка. Итог зависит от порядка `<link>` в документе.
