Информация для донов!

Для каждого описанного в лекции свойства добавлены и сгруппированы примеры кода.
Рекомендую параллельно читать лекцию и изучать файлы в папке Примеры кода.


*************************************************

Итак, донам доступны
- примеры кода с комментариями и небольшими заданиями
- пример реализации выпадающего списка в меню без использования JavaScript
- верстка по макету
- настройка стилизации таблиц + крутой пример как скрыть и показать часть контента на странице без использования JavaScript
- дополнительная мини-лекция по настройке внешнего вида курсора
- пошаговая инструкция для выполнения практической работы с примерами кода и готовым проектом
