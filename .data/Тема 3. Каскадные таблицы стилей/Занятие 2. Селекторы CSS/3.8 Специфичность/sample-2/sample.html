Вес специфичности селекторов

Селекторы расположены по возрастанию специфичности

  • селекторы типов элементов (например, h1) и псевдоэлементов;
  • селекторы классов (например, .example), селекторы атрибутов (например, [type="email"]) и псевдоклассов;
  • селекторы идентификаторов (например, #example).
Ниже представлены абзацы текста. Для каждого из них задан свой цвет текста. Перейдите в файл со стилями и раскомментируйте поочередно правила для типа элемента, элемента с определенным классом и идентификатором.

Для элемента span заданы два класса. Измените порядок классов в файле со стилями и оцените как изменится оформление элементов.

Два селектора класс имеют одинаковый вес, поэтому к элементу будут применяться те свойства, которые записаны в стилях последними.
