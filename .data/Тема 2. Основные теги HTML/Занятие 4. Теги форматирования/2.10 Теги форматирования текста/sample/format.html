Элемент code

Чтобы представить несколько строк кода, оберните ‹code› элемент внутри ‹pre› элемента.

Сам по себе элемент ‹code› представляет собой только одну фразу кода или строку кода.

Элемент samp

Оформляем текст как вывод данных.

Например, описываем в тексте некоторую реакцию программы и приводим пример: Вот текст который выдаст пользователю программа И продолжаем описание...

Допустимо совмещать разные элементы и дополнительные стили для достижения лучшего эффекта.
