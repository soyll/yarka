Элементы формы. Input

Ввод числовой информации. Number. Range.

Поле для выбора позиции: input type="range"

Проверка шаблона для элемента недоступна, однако выполняются следующие формы автоматической проверки:

  • Если в значение value установлено что-то, что не может быть преобразовано в действительное число с плавающей запятой, проверка завершится ошибкой.
  • Значение не должно быть меньше min. Значение по умолчанию – 0.
  • Значение не должно быть больше max. По умолчанию 100.
  • Значение будет кратно step. По умолчанию 1.

Поле для ввода чисел: input type="number"
