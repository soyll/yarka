Элементы формы. Input. Дата и время

Для ввода информации о времени и дате
используются специальные типы поля input.

Поле для ввода даты: input type="date"

Выбор числа, месяца и года на календаре.

Поле для ввода даты и времени: input type="datetime-local"

К календарю добавляется дополнительная панель.

Поле для ввода номера недели и года: input type="week"

Номер недели в году и непосредственно год.

Поле для ввода времени: input type="time"

Выбираем время в формате часы:минуты | {0-23}:{0-59}

Поле для ввода названия месяца и года: input type="month"

Выберите значение месяца из списка, начните набирать его название или нажмите на клавиатуре цифру, соответствующую порядковому номеру месяца в году.
