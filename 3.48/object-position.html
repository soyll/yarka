Заполнение контейнера изображением

Исходный размер наших изображений 600 на 600 точек. Искусственно задаем им размер 150 на 200.

Установим значения object-fit на contain или none.

А расположение будем редактировать с помощью object-position

contain + top

contain + bottom

none + left

none + right

contain + object-position: 25% 75%

contain + object-position: 10% 100%

none center

none + object-position: 25% 75%
