# Задание 3.15. Плавающие элементы

## Что сделано

Изучен файл примера в папке `sample` (index.html и блок `<style>` с вариантами `float` и `clear`).

### Итоги

- **float: left / right** — элемент выносится из потока, остальной контент обтекает его слева или справа. Несколько элементов с `float: left` выстраиваются в ряд.
- **clear: left / right / both** — отмена обтекания: блок с `clear` начинается ниже плавающих элементов. `clear: both` — ниже всех.
- Если у контейнера все дети с `float`, высота контейнера схлопывается (дети вышли из потока). Решение: `clear` у псевдоэлемента после контейнера или у следующего блока.
- **display: none** у одного из плавающих элементов: соседние сдвигаются, обтекание пересчитывается.

В примере переключение `float` и `clear` в комментариях меняет расположение картинок и текста; при выделении блока в DevTools видно, что плавающие изображения выходят за границы родителя.
