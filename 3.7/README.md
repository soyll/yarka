# Задание 3.7. Настройка стилей

## Что сделано

- В папке `sample` к странице **index.html** подключён файл стилей **assets/css/style.css**.
- К элементам добавлены классы из набора утилит:
  - **first-page:** `bg-primary`, `text-white`, `text-center`, `p-2`; заголовки — `text-4`, `text-2`.
  - **items:** у контейнера — `p-2`, у обёртки карточек — `d-flex-wrap`, `justify-content`; у заголовка — `text-dark`, `text-center`, `mb-2`; у каждой карточки `.item` — `text-dark`, `p-1`, `m-1`; у подзаголовков в карточках — `text-2`, у описаний — `text-1`; у кнопок — `btn-next`.
  - **footer:** `bg-primary`, `text-white`, `text-center`, `p-2`, `mt-2`; у параграфов — `text-1`.

Внешний вид приведён к эталону: синяя шапка и подвал, центрирование, сетка карточек с отступами, оформленные кнопки.
