# Задание 3.27. Закреплённое меню

## Что сделано

В папке `sample` в **index.html** в блоке `<style>` добавлены правила:

- **nav** — `position: sticky; top: 0;` (меню остаётся у верхнего края при прокрутке).
- Ссылка «Наверх» с классом **.top_btn**: добавлена перед `</body>`, атрибуты `href="#"`, `title="Вернуться к началу"`. Стили .top_btn: `width: 100px`, `text-align: center`, `position: fixed`, `bottom: 100px`, `right: 25px` (кнопка закреплена в правом нижнем углу окна).

При прокрутке навигация прилипает к верху, кнопка «Наверх» всегда видна справа внизу и по клику возвращает к началу страницы.
