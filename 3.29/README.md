# Задание 3.29. Примеры кода (границы, тени)

## Что сделано

Изучены примеры в папке задания (border-style, border-radius, border-collapse, box-shadow, text-shadow, outline, current-color и др.).

### Итоги

- **border** — толщина, стиль, цвет; по сторонам (border-top и т.д.), сокращения.
- **border-radius** — скругление углов.
- **box-shadow** — тень блока (смещение, размытие, цвет, inset).
- **text-shadow** — тень текста.
- **outline** — обводка без влияния на блочную модель.
- **currentColor** — использование текущего значения color в других свойствах.

Изменение значений в примерах показывает влияние на отображение элементов.
