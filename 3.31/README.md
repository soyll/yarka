# Задание 3.31. Верстка по макету (Турист PRO)

## Что сделано

В папке `sample` дополнены и проверены стили в **style/style.css** для соответствия эталону страницы index.html.

- Использованы имеющиеся правила: сброс отступов, .wrapper и .content (80%, центрирование), шапка (flex, space-between), баннер (фон, min-height, заголовок), блок алгоритма (фон #04323a, шаги в flex), блок «О компании» (комментарии в три колонки, float), поиск (поля и кнопки на всю ширину), акции (promos — flex wrap, promo — 31%), подвал (фон, заголовок, навигация).
- Создан файл **style/style-alt.css** — альтернативное оформление: тёмная тема (тёмно-синие и тёмно-серые фоны), светлый текст, акцентный цвет кнопок (#e94560). Для подключения альтернативы в index.html можно заменить ссылку на style.css на style-alt.css или подключить style-alt.css после style.css для переопределения.
