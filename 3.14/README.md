# Задание 3.14. Переопределение свойств

## Что сделано

В папке `sample` в **index.html** в блоке `<style>` переопределены значения свойства `display` по умолчанию:

- **.text p** — `display: inline` (абзацы идут в одну строку, перенос по содержимому).
- **.select span**, **.select a** — `display: block` (ссылки и span занимают всю ширину, с новой строки).
- **.list ol li** — `display: inline` (пункты списка в одну линию).
- **.gallery img** — `display: block` (каждое изображение с новой строки).

В DevTools видно: у блочных элементов (p, li) при `display: inline` блок перестаёт растягиваться на всю ширину; у строчных (span, a) при `display: block` появляется блочная модель и перенос.
